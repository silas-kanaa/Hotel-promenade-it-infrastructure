# Hotel de la Promenade – IT Infrastructure Project

## Project Overview

Academic team project completed at La Cité College as part of the Server Management course.

The objective was to design, configure, and document a centralized IT infrastructure for a fictional hotel using Windows Server 2019, Active Directory, network storage, backup solutions, and Microsoft 365 services.

## Technologies Used

- Windows Server 2019
- Windows 10
- Active Directory Domain Services (AD DS)
- DNS
- Group Policy Objects (GPO)
- NTFS permissions
- TrueNAS
- SMB
- Veeam
- SharePoint Online
- Microsoft 365

## Infrastructure Components

- Two Windows Server 2019 domain controllers
- Three Windows 10 client computers
- Active Directory and DNS services
- Centralized user and group management
- TrueNAS network storage
- Veeam backup solution
- SharePoint Online migration test

## Key Activities

### Server Administration
- Configured Windows Server 2019 infrastructure.
- Installed and configured Active Directory Domain Services.
- Added a secondary domain controller.
- Configured DNS services and examined directory replication.

### Identity and Access Management
- Created organizational units and security groups.
- Managed user accounts and permissions.
- Configured NTFS and shared-folder permissions.
- Implemented Group Policy for automatic network drive mapping.

### Storage and Backup
- Integrated TrueNAS into the infrastructure.
- Configured SMB network shares.
- Set up backup jobs using Veeam.

### Cloud Integration
- Conducted a file migration test to SharePoint Online using SharePoint Migration Tool.
